# 每日運勢整合引擎 DAILY_ENGINE（v2.0）

入口：`src/engines/daily/index.ts` → `computeDailyReport(profile, "YYYY-MM-DD")`

## 1. 八大運勢
綜合運、工作事業、財運投資、感情家庭、健康身心、人際貴人、出行旅遊、學習文書。

## 2. 資料流
每一條判斷都是一個 `Evidence`（術語、專業說明、白話、古籍原文、對各運勢的加減分），畫面上可逐條點開，分數完全可追溯。

| 系統 | 依據 | 個人化來源 |
|---|---|---|
| 八字 | 流日天干十神×喜忌、流日地支本氣喜忌、流日地支對年月日時四柱之沖／六合／三合／刑、伏吟反吟、天干五合、大運、流年 | 四柱、日主強弱、喜用、大運、性別（男財女官論配偶） |
| 滴天髓 | 十干論逐句條件（如庚「得火而銳」、戊「若在艮坤，怕沖宜靜」）、〈寒暖〉調候、〈衰旺〉「旺者沖衰衰者拔」（沖去忌神轉吉） | 日主天干、出生季節、日支、命局地支 |
| 神煞 | 天乙貴人、文昌、祿神、羊刃、驛馬、桃花、華蓋 | 日干、年支、日支 |
| 紫微 | 流日命宮（斗君法）宮內吉煞星、流日天干四化入本命宮、流年四化（權重 0.4） | 命盤十二宮、生月、生時 |
| 奇門 | 以年命（出生年干，甲遁旬首儀）為自身；各主題取用神（開門／生門／六合／天心／值符／九天／景門），評門星神、門迫、空亡、天地盤格局（青龍返首、飛鳥跌穴…），並以用神宮與年命宮五行生剋加權；取白天（辰–酉）六個時辰平均 | 出生年干 |
| 易經 | 梅花易數年月日時起卦：（流日農曆年支數＋月＋日）得上卦，再加「本人出生時辰數」得下卦與動爻；本卦／互卦／變卦、體用生剋、動爻爻位（二多譽、三多凶、四多懼、五多功） | 出生時辰 |

## 3. 評分
- 各系統權重：八字 1.0、滴天髓 0.9、神煞 0.8、紫微 0.8、奇門 1.0、易經 0.8。
- 分項分數 = 50 + (分項加減 + 0.4 × 綜合加減) × 2.6 × 可信度係數。
- 綜合運 = 綜合加減分與七項平均各半，再以 1.3 倍拉開離散度。
- 可信度係數：時辰確定 1.0、大約 0.85、不確定 0.65（向 50 收斂）。

## 6. 限制
- 分數代表傳統命理的「傾向」，不是預測；請搭配首頁「這天準嗎？」回饋累積自己的命中率。
- 紫微流日命宮採斗君法一派；奇門為時家轉盤拆補法；神煞採子平通行起例。學派不同結果會有差異。
