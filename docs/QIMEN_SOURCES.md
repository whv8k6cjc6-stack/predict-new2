# 奇門遁甲：格局依據與出處

> 引文由 [qimen-dunjia](https://github.com/arc119226/qimen_dunjia)（MIT）逐字錄自各書，存於 `src/data/classics/qimen/citations.json`；本專案**未對照原刊影像**，App 中標為「錄文」。古籍原文屬公有領域；十干克應的吉凶欄是該軟體依斷語所判，不是典籍所標。

## 排盤
- 時家轉盤、拆補法、符頭定元、中五寄坤（《統宗》《寶鑑》「中五合於坤二」）。
- 與對照組逐層比對：`src/tests/qimen-oracle.test.ts`（1000 個隨機時刻）。
- 寄宮的其他說法、置閏法目前沒有可核對的依據或對照實作，未提供。

## 格局（每則附書名、篇名、原文）
| 格局 | 依據 | 讀法／說明 | 用途 |
|---|---|---|---|
| 五不遇時 | 煙波釣叟歌；《遁甲演義》葛洪注；《寶鑑》〈釋五不遇時〉 | 干支定式（十組） | 不列為較佳時段、優先列入應避開；事件規則 |
| 五不遇時（寬） | 《法竅》〈論五不遇時〉 | 陽克陽、陰克陰（含定式外 2 格） | 時段排序小幅減分 |
| 伏吟 | 《旨歸》卷五 | 天盤與地盤全同 | 時段排序、事件規則 |
| 反吟 | 煙波釣叟歌（《旨歸》錄本） | 值符星落本位對宮 | 時段排序、事件規則 |
| 門伏吟／門反吟 | 未找到引文 | 只顯示、不計分 | — |
| 門迫／宮迫／和義 | 《法竅》卷一賦與註、〈論八門迫制〉 | 宮迫為書內異說，減半計 | 宮位評分 |
| 十干克應 81 格 | 《奇門旨歸》卷五〈十干克應〉（以《秘笈大全》為校） | 《統宗》四十格亦列者權重較大；中性格不計 | 宮位評分；斷語只放專業模式原文 |
| 六儀擊刑 | 《法竅》〈論六儀擊刑〉、《寶鑑》〈釋六儀擊刑〉 | 嚴式（值符之儀）計分、觸發規則；寬式小幅計 | 宮位評分、事件規則 |
| 三奇入墓 | 《統宗》〈奇門四十格〉、《旨歸》、《寶鑑》 | 丁奇有「墓艮八」「墓乾六」兩說，後者不觸發規則 | 宮位評分、事件規則 |
| 三奇得使 | 《統宗》〈奇門四十格〉 | — | 宮位評分、事件規則 |
| 天遁、地遁、人遁 | 《法竅》、煙波釣叟歌、《景祐符應經》 | — | 宮位評分、事件規則 |
| 截路空亡 | 《奇門遁甲元靈經》 | 只影響出行類事件 | 出行時段、事件規則 |

所有判定與對照組的 `detect*` 逐格比對：`src/tests/qimen-patterns.test.ts`（600 個隨機時刻）。

## 設定
- 代表自己的天干：出生年干（年命，預設）或當天日干（擇時常用），在「設定 → 計算設定」切換。
- 擇時事件指定時刻可用真太陽時（所在地經度＋均時差）。
