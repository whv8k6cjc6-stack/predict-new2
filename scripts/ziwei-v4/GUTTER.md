# 書縫區逐字轉錄任務（獨立核讀）

《紫微斗數全書》掃描是左右兩頁併成一張；中間書縫附近的一兩行正文常被切成兩半，先前的轉錄沒有涵蓋。這次請轉錄書縫區。

- **只能看指定的 PNG 影像**；不要讀任何其他檔案（不要讀程式碼庫、其他轉錄、OCR），不要用 OCR。可以自己裁切放大影像來看。
- 影像目錄：`/tmp/claude-0/-home-user-predict-new2/01f10233-de6f-5109-a4de-ba868ea9ebc3/scratchpad/cols/g/`，檔名 `p{頁}_g_{a|b}.png`：該頁跨頁影像中間區域（頁寬 44%–56%），a＝上半、b＝下半（中間約 4% 重疊）。
- 區域內通常有：右頁最左一兩行正文、中間的版心（書名「紫微斗數」、卷次、頁碼）、左頁最右一兩行正文。

## 規則
1. 由右到左列出區域內每一個**正文直行**（版心的書名／卷次／頁碼另外寫在 `banxin`，不要混入正文）。
2. 每行由上到下照印刷原字轉錄，不加標點、不改字、不補字。a、b 兩半分開寫，同一行在兩半的順序要對應；某行在某半沒有字就留空。
3. 行被影像左右邊緣切掉一部分、字不完整：看得清的照寫，看不清的寫 `〔疑字：X〕`（X 為最可能讀法）或 `〔缺字〕`；**不要猜**。
4. 雙行小字夾注以 `〈〉` 包住（右小行再左小行）。
5. 每一行標明它在影像中的位置：`side` 為 `right`（右頁）或 `left`（左頁）。
