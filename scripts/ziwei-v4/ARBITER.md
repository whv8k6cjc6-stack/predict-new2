# 差異決議任務（回原始影像定字）

兩位轉錄員各自獨立轉錄了《紫微斗數全書》掃描影像，程式比對出他們不一致或標為存疑的位置。你要**看影像**決定每一處的正確文字。

- 每一處都有一張裁切影像（由左到右拼成一張，對應清單順序 #0、#1、…），影像左緣紅色短線大約標出位置（可能有一兩個字的誤差，請依前後文字對齊找出該字）。
- 影像檔：編號 `26L_0#3` 的影像在 `res2/26L_0.png` 由左數第 4 張（#0 起算）。清單在 `res2/{葉}_list.txt`。
- 清單每行（tab 分隔）：`編號 穩定鍵 s欄組 種類 A=轉錄員A B=轉錄員B ctx=上下文（【】內為爭議處，｜分隔 A／B）`。
- 種類 diff＝兩人讀法不同；doubt＝兩人讀法相同但至少一人標為存疑。
- 若裁切影像看不到目標字，可用 `ZOUT=/tmp/claude-0/-home-user-predict-new2/01f10233-de6f-5109-a4de-ba868ea9ebc3/scratchpad/res2/zoom_{你的批次}.png python3 /tmp/claude-0/-home-user-predict-new2/01f10233-de6f-5109-a4de-ba868ea9ebc3/scratchpad/zooms2.py "<編號>:<y 偏移>"` 產生 `res2/zoom_{你的批次}.png` 再看（偏移為頁高比例，例如 0.06 往下、-0.05 往上）。**只能用這個工具看影像，不要讀其他檔案、不要用 OCR。**

## 決議規則
1. 只依影像字形判斷，不依文意猜字，不依記憶補字。
2. 能確定：寫出正確文字（可能是 A、B 其中一個，也可能兩個都錯）。字形是常見異體字時寫通行正體（例：寍→寧、刼→劫）。
3. 若爭議是「某人漏了字／多了字」，寫出影像上實際存在的文字；影像上沒有字就寫 `_`（空字串）。
4. **不能百分之百確定就寫 `?`**。寧可存疑，不要猜。
5. 行分隔符 `|` 的差異：依影像判斷那裡是否換行；是換行就寫 `|`，不是就寫 `_`。

## 輸出
把決議寫成一個 JSON 檔：`/tmp/claude-0/-home-user-predict-new2/01f10233-de6f-5109-a4de-ba868ea9ebc3/scratchpad/res2/arb_{你的批次}.json`，格式：
```json
{"26L_0#1": {"value": "員", "why": "上口下貝"}, "29L_0#0": {"value": "?", "why": "上半墨點不清"}}
```
每個編號都要有一筆。完成後回覆一行：總數、確定數、存疑數。

- 編號沿用清單第一欄（如 `26L_0#3`）。只處理指派給你的葉面清單，不要動其他檔案。
