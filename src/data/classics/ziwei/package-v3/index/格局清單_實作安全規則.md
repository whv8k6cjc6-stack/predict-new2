# 格局清單：實作安全規則

## 原則

《紫微斗數全書》不同版本可見「定富局、定貴局、定貧賤局、定雜局」等章目，但本包的主來源是廣益版掃描。
在沒有逐字對照廣益版頁面前：

- 格局名稱可作 `patternCandidate`。
- 不可直接 `verified`。
- 不可直接設定固定吉凶分數。
- 不可只因名稱相同就認定成立條件相同。
- 「見前批註」類條目必須回查前文，不能把名稱本身當完整條件。

## 第一批可先人工核對的候選

### 定富局（候選章目）
可優先回原頁找以下名稱：
- 財蔭夾印
- 日月夾財
- 財祿夾馬
- 蔭印拱身
- 日月照璧
- 金燦光輝

### 定貴局
此類條目多，且不少只寫「見前批註」。工程上請先把它當**索引型格局表**，每條都需回查前文條件；不要一次批量啟用。

### 定貧賤局
古文標籤帶有強烈階級／宿命色彩。可以保存原文，但現代 Interpretation 應拆成中性結構因素，不得對使用者下「貧」「賤」人格或命運判決。

### 定雜局
多與運限、時勢變化有關。應優先建模成 `NatalContext + PeriodModifier`，不要直接塞進本命固定分數。
