## OCR 使用

`ocr/紫微斗數全書_p17-p55_機器OCR_僅供搜尋.txt` 是低信度導航稿：
- 只供搜尋星名／宮名／關鍵詞。
- 古籍直排、墨污、舊字形導致誤辨很多。
- **禁止直接作 originalText、禁止 exact citation、禁止評分。**

## 建議的 verified 流程

`PDF頁影像 → 人工逐字核對 → citation locator → originalText exact transcription → SHA/版本 → verified InterpretationRule → LifeFactor → Advice`
