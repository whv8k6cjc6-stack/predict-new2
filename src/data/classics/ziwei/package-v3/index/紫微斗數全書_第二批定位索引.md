### 使用方式

這些頁面不是「每宮一段總論」，而是密集列出各星曜、同宮、煞曜、吉曜在該宮位的條件式判斷。建議開發時：

1. 先以宮位章首作 `PalaceClassicalSection` 的 citation locator。
2. 不要把整章自動濃縮成單一吉凶標籤。
3. 只有逐字核對成功的星曜／宮位條文，才建立 `InterpretationRule`。
4. 借星、廟旺、四化等若條文沒有數值權重，App 不得自行建立百分比或固定加減分。
