## 4. 集文版定位

《紫微斗數全集-集文版》實際為《合併十八飛星紫微斗數全集》類型的合編文本，結構不等同廣益版《全書》。掃描解析度亦較低。

使用策略：
- 可記錄平行段落 locator。
- 無法清楚逐字者：`visualVerified=false`。
- 不因「沒比出異文」就宣稱兩版相同。
- 不作 primary rule source。
