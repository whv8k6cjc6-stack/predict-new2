### 狀態

- `structureVerified = true`
- `ocrUsableForSearch = true`
- `exactRuleTranscription = columnWiseRequired`
- `bulkOcrImportAllowed = false`

這些頁不能因 OCR 能搜尋就直接變成 enabled rule。應逐欄拆成 Condition + Citation；任何一欄若有疑字，該 rule 保持 pending。
